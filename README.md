# Commands

## NPC
- `/npcspawn`  
  Spawn companion NPC.
- `F` (while looking at spawned NPC)  
  Toggle follow on/off (Does NOT work in Creative).

## Crimson Infection
- `/redpos1`  
  Set area corner 1 at your feet.
- `/redpos2`  
  Set area corner 2 at your feet.
- `/redstart <seconds>`  
  Start spread in selected area.  
  `seconds` = total spread duration.
- `/redundo`  
  Undo last spread and restore original blocks.
  Infected blocks damage the player (5 hp/s)
